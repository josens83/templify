# Templify - 템플릿 마켓플레이스 플랫폼

웹사이트 템플릿을 사고팔고, 전문가 매칭 서비스를 제공하는 통합 플랫폼입니다.

## 🚀 주요 기능

### 1. 템플릿 마켓플레이스
- **30개 이상의 프리미엄 템플릿** - 쇼핑몰, 포트폴리오, SaaS, 블로그, 관리자 대시보드 등
- **카테고리별 분류 및 필터링** - 원하는 템플릿을 쉽게 찾을 수 있습니다
- **상세 검색 및 정렬** - 가격, 평점, 인기도, 최신순으로 정렬
- **실시간 미리보기** - 구매 전 템플릿을 미리 확인
- **평점 및 리뷰 시스템** - 실제 사용자들의 피드백

### 2. 전문가 매칭 서비스
- **20명 이상의 검증된 전문가** - 풀스택, 프론트엔드, 백엔드, 디자이너, 모바일 개발자
- **전문 분야별 필터링** - 프로젝트에 맞는 전문가 찾기
- **포트폴리오 및 프로필** - 전문가의 실력과 경험 확인
- **시간당 요율 비교** - 예산에 맞는 전문가 선택
- **실시간 응답 시간** - 빠른 커뮤니케이션

### 3. 커뮤니티 기능
- **Q&A 포럼** - 개발 관련 질문과 답변
- **아티클 공유** - 기술 블로그 및 튜토리얼
- **쇼케이스** - 프로젝트 결과물 공유 및 피드백
- **태그 시스템** - 관심 주제별 검색

### 4. 사용자 기능
- **장바구니 시스템** - 여러 템플릿을 한 번에 구매
- **찜하기 기능** - 관심 있는 템플릿을 저장하고 나중에 구매 (실시간 UI 연동)
  - 템플릿 카드 하트 버튼으로 즉시 찜하기/취소
  - 템플릿 상세 페이지에서 찜하기
  - Header에 찜하기 카운트 표시
  - 찜한 템플릿 전용 페이지
- **최근 본 템플릿** - 사용자가 본 템플릿 자동 추적 및 표시
  - 템플릿 상세 페이지 조회 시 자동 기록
  - 홈 페이지에 최근 본 템플릿 섹션 표시
  - 최대 10개까지 저장, 최신순 정렬
- **로컬 스토리지 활용** - 장바구니, 찜하기, 최근 본 템플릿, 사용자 정보 유지
- **다크모드 지원** - 눈의 피로를 줄이는 다크 테마
- **반응형 디자인** - 모바일, 태블릿, 데스크톱 모두 지원
- **설정 관리** - 프로필, 결제 정보, 알림, 보안 설정
- **개선된 네비게이션** - 사용자 드롭다운에서 모든 기능 접근

### 5. 판매자 기능
- **판매 대시보드** - 실시간 판매 통계 및 수익 분석
- **템플릿 업로드** - 간편한 템플릿 등록 및 미리보기
- **수익 추적** - 월별 수익 추이 및 템플릿별 성과
- **메시지 시스템** - 구매자와의 실시간 소통
- **판매 관리** - 최근 판매 내역 및 구매자 정보

## 🛠 기술 스택

- **Frontend Framework**: React 18 + TypeScript
- **Build Tool**: Vite
- **Styling**: Tailwind CSS
- **Routing**: React Router v6
- **State Management**: React Context API
- **Icons**: Lucide React
- **Type Safety**: TypeScript

## 📦 설치 및 실행

### 사전 요구사항
- Node.js 18 이상
- npm 또는 yarn

### 설치
```bash
# 의존성 설치
npm install

# 개발 서버 실행
npm run dev

# 빌드
npm run build

# 프리뷰
npm run preview
```

## 🌐 페이지 구성

### 주요 페이지
- **홈페이지** (`/`) - 인기 템플릿 및 추천 전문가
- **템플릿 마켓** (`/templates`) - 전체 템플릿 목록 및 검색
- **템플릿 상세** (`/templates/:id`) - 상세 정보, 리뷰, 관련 템플릿
- **전문가 찾기** (`/experts`) - 전문가 목록 및 필터링
- **전문가 상세** (`/experts/:id`) - 프로필, 포트폴리오, 프로젝트 의뢰
- **커뮤니티** (`/community`) - Q&A, 아티클, 쇼케이스
- **가격 정책** (`/pricing`) - 멤버십 플랜 및 수수료 안내

### 사용자 페이지
- **회원가입** (`/signup`) - 신규 사용자 등록
- **로그인** (`/login`) - 사용자 인증
- **장바구니** (`/cart`) - 선택한 템플릿 관리
- **찜하기** (`/wishlist`) - 관심 템플릿 저장 및 관리
- **결제** (`/checkout`) - 카드 정보 입력 및 결제
- **대시보드** (`/dashboard`) - 구매 내역, 통계, 배지
- **설정** (`/settings`) - 프로필, 결제 정보, 알림, 보안 설정

### 판매자 페이지
- **판매자 대시보드** (`/seller-dashboard`) - 판매 통계, 수익 관리, 템플릿 현황
- **템플릿 업로드** (`/upload-template`) - 새 템플릿 등록 및 미리보기
- **메시지 센터** (`/messages`) - 구매자-판매자 간 실시간 메시징

### 기타
- **404 페이지** (`*`) - 페이지를 찾을 수 없음

- 판매 가격의 **15-30%** 수수료
- 판매자는 70-85% 수익 보장

### 2. 전문가 매칭 수수료
- 프로젝트 금액의 **10-20%** 수수료
- 에스크로 시스템을 통한 안전한 거래

### 3. 프리미엄 멤버십
- 월 구독 서비스
- 무제한 템플릿 다운로드
- 우선 전문가 매칭

## 📱 주요 컴포넌트

### Layout
- `Header` - 네비게이션, 검색, 찜하기, 장바구니, 다크모드 토글, 사용자 드롭다운
- `Footer` - 링크, 소셜 미디어, 연락처
- `Layout` - 전체 페이지 레이아웃

### Components
- `TemplateCard` - 찜하기 버튼이 포함된 재사용 가능한 템플릿 카드 컴포넌트

### Pages
- `Home` - 메인 랜딩 페이지
- `Templates` - 템플릿 마켓플레이스
- `TemplateDetail` - 템플릿 상세 페이지
- `Experts` - 전문가 찾기
- `ExpertDetail` - 전문가 상세 프로필
- `Community` - 커뮤니티 포럼
- `Cart` - 장바구니
- `Wishlist` - 찜한 템플릿 목록
- `Checkout` - 결제 페이지
- `Dashboard` - 구매자 대시보드
- `SellerDashboard` - 판매자 대시보드
- `UploadTemplate` - 템플릿 업로드
- `Settings` - 사용자 설정
- `Messages` - 메시지 센터
- `Login` - 로그인
- `Signup` - 회원가입
- `Pricing` - 가격 정책
- `NotFound` - 404 페이지

### Context
- `AppContext` - 전역 상태 관리 (장바구니, 찜하기, 최근 본 템플릿, 사용자, 테마)
